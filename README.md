# 🏫 School Management System

## 🚀 About the Project

Hi! 👋
I built this **School Management System** as a real-world project for my father’s school. The goal was to create a digital platform where all important school information and activities can be managed and displayed in an organized way.

While working on this project, I tried to go beyond just functionality and focused on **design, user experience, and meaningful features** that make the website feel interactive and engaging.

This project helped me understand how to build a **complete production-like application** using the MERN stack.

---

## 🧠 What I Learned

* Building real-world applications for actual users
* Structuring large-scale projects (Admin + Frontend + Backend)
* Managing dynamic data using MongoDB Atlas
* Media handling using Cloudinary
* Designing engaging UI/UX (animations, layout, transitions)
* Handling admin-controlled content systems

---

## 🛠️ Tech Stack

* **Frontend:** React.js, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB Atlas
* **Media Storage:** Cloudinary

---

## ⚙️ Installation & Setup

1. Clone the repository

```bash id="k29xg2"
git clone https://github.com/your-username/school-management-system.git
```

2. Install dependencies

```bash id="m11pz8"
cd frontend
npm install

cd ../backend
npm install

cd ../admin
npm install
```

3. Setup environment variables (.env)

* MongoDB Atlas connection
* Cloudinary credentials
* JWT secret (if used)

4. Run the project

```bash id="u88zq3"
npm run dev
```
